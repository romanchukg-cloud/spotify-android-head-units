Експериментальний плеєр Spotify Automotive для Android-магнітол. Інтерфейс на основі BYD та музичний сервіс об’єднані в одному APK з однією іконкою і штатним входом Spotify.

[Завантажити тестовий APK](https://github.com/romanchukg-cloud/spotify-android-head-units/releases/tag/v5.5.0-unified-test.2) · [🌐 Spotify для Android-магнітол](https://romanchukg-cloud.github.io/spotify-android-head-units/uk/)

## Що вже перевірено

Перевірено на BYD DiLink5 з Android 12: оновлення зі збереженням входу, Home, Recents, Library і треки в плейлистах. Під час відкриття плейлистів музика продовжувала грати; вибір треку запускав відтворення. Користувач підтвердив, що закриття додатка зупиняє музику. Вхід за QR-кодом також перевірено на емуляторі Android 35.

**Експериментальний тестовий реліз .2.** Кнопки на кермі, офлайн-завантаження та інші магнітоли ще потребують перевірки.

Потрібен Android 9 або новіший. Сумісність із магнітолами інших виробників ще не перевірена; це не універсальна збірка.

## Як встановити

1. Завантажте APK з GitHub Releases і перенесіть у мультимедійну систему.
2. Нашу попередню тестову збірку з тим самим підписом оновлюйте без видалення: авторизація може зберегтися. Збірки з іншим підписом так не оновляться.
3. Відкрийте Spotify й за потреби увійдіть через QR-код.
4. Перевірте музику та керування. Старий окремий інтерфейс BYD видаляйте після успішної перевірки нового APK.
