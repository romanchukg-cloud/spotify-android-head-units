Headunit-test.5: аудит APK — 28 PASS / 0 FAIL. На емуляторах Android 9 і 15 перевірено затримку готовності плеєра, втрату першої команди Play, підтвердження відтворення, скасування після паузи та захист під час зміни акаунта. Налаштування без входу й правила медіакерування також пройшли перевірку. Реальний звук після сну чи перезавантаження авто ще потребує перевірки.

**Експериментальна headunit-test.5.** Ще не перевірені перегляд і звук після входу, справжнє перемикання A → B → A, офлайн-завантаження, кнопки керма, фактичне відновлення звуку після сну/перезавантаження та регресія на BYD/AAOS.

Потрібен Android 9+ (API 28); Android 8 — наступний етап. Реалізовані профілі BYD, AAOS і GENERIC; у цій збірці перевірений лише GENERIC. Реальні магнітоли інших виробників та AAOS ще не перевірені.

## Як встановити

1. Завантажте APK з GitHub Releases і перенесіть у мультимедійну систему.
2. Нашу попередню тестову збірку з тим самим підписом оновлюйте без видалення: авторизація може зберегтися. Збірки з іншим підписом так не оновляться.
3. Відкрийте Spotify й за потреби увійдіть через QR-код.
4. Щоб додати іншого водія: Налаштування магнітоли → Акаунти → Додати акаунт · QR. Перемикання зупиняє музику й перезапускає плеєр.
5. Перевірте музику та керування. Старий окремий інтерфейс BYD видаляйте після успішної перевірки нового APK.
