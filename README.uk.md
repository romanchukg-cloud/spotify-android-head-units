# Spotify для Android-магнітол

[English](README.md) · [Українська](README.uk.md) · [Русский](README.ru.md) · [العربية](README.ar.md) · [简体中文](README.zh-Hans.md)

Експериментальний плеєр Spotify Automotive для Android-магнітол. Інтерфейс на основі BYD та музичний сервіс об’єднані в одному APK з однією іконкою і штатним входом Spotify.

[Завантажити тестовий APK](https://github.com/romanchukg-cloud/spotify-android-head-units/releases/tag/v5.5.0-headunit-test.3) · [🌐 Spotify для Android-магнітол](https://romanchukg-cloud.github.io/spotify-android-head-units/uk/)

## Що вже перевірено

Headunit-test.3: аудит APK — 23 PASS / 0 FAIL; 16 перевірок логіки на звичайних емуляторах Android 9, 11, 13 і 15. Екран входу без авторизації та налаштування перевірені на 800×480@160, 1024×600@160, 1280×720@240, 1920×720@240 і 768×1024 у портреті. Окремий клієнт MediaBrowserCompat отримує корінь, коли зовнішнє керування дозволене, та відмову, коли вимкнене. Перезавантаження Android 11 скидає блокування й відправляє запит відновлення. Попередня test.2 перевірялася на BYD DiLink5; це не підтверджує роботу нової збірки.

**Експериментальна headunit-test.3.** Ще не перевірені Home, медіатека, плейлисти й звук після входу, медіакнопки при закритому або мертвому процесі, «Назад» із Now Playing, фактичне відновлення після сну/перезавантаження, офлайн-завантаження та регресія BYD DiLink5. Експеримент із кількома акаунтами не включений.

Потрібен Android 9+ (API 28); Android 8 — наступний етап. Реалізовані профілі BYD, AAOS і GENERIC; у цій збірці перевірений лише GENERIC. Реальні магнітоли інших виробників та AAOS ще не перевірені.

## Як встановити

1. Завантажте APK з GitHub Releases і перенесіть у мультимедійну систему.
2. Нашу попередню тестову збірку з тим самим підписом оновлюйте без видалення: авторизація може зберегтися. Збірки з іншим підписом так не оновляться.
3. Відкрийте Spotify й за потреби увійдіть через QR-код.
4. Перевірте музику та керування. Старий окремий інтерфейс BYD видаляйте після успішної перевірки нового APK.
