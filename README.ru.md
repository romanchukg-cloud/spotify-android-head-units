# Spotify для Android-магнитол

[English](README.md) · [Українська](README.uk.md) · [Русский](README.ru.md) · [العربية](README.ar.md) · [简体中文](README.zh-Hans.md)

Экспериментальный плеер Spotify Automotive для Android-магнитол. Интерфейс на основе BYD и музыкальный сервис объединены в одном APK с одним значком и стандартным входом Spotify.

[Скачать тестовый APK](https://github.com/romanchukg-cloud/spotify-android-head-units/releases/tag/v5.5.0-headunit-test.3) · [🌐 Spotify для Android-магнитол](https://romanchukg-cloud.github.io/spotify-android-head-units/ru/)

## Что уже проверено

Headunit-test.3: аудит APK — 23 PASS / 0 FAIL; 16 проверок логики на обычных эмуляторах Android 9, 11, 13 и 15. Экран входа без авторизации и настройки проверены на 800×480@160, 1024×600@160, 1280×720@240, 1920×720@240 и 768×1024 в портрете. Отдельный клиент MediaBrowserCompat получает корень при разрешённом внешнем управлении и отказ при выключенном. Перезагрузка Android 11 сбрасывает блокировку и отправляет запрос восстановления. Предыдущая test.2 проверялась на BYD DiLink5; это не подтверждает работу новой сборки.

**Экспериментальная headunit-test.3.** Ещё не проверены Home, медиатека, плейлисты и звук после входа, медиакнопки при закрытом или мёртвом процессе, «Назад» из Now Playing, фактическое восстановление после сна/перезагрузки, офлайн-загрузки и регрессия BYD DiLink5. Эксперимент с несколькими аккаунтами не включён.

Требуется Android 9+ (API 28); Android 8 — следующий этап. Реализованы профили BYD, AAOS и GENERIC; в этой сборке проверен только GENERIC. Реальные магнитолы других производителей и AAOS ещё не проверены.

## Как установить

1. Скачайте APK из GitHub Releases и перенесите в мультимедийную систему.
2. Нашу предыдущую тестовую сборку с той же подписью обновляйте без удаления: авторизация может сохраниться. Сборки с другой подписью так не обновятся.
3. Откройте Spotify и при необходимости войдите по QR-коду.
4. Проверьте музыку и управление. Удаляйте старый отдельный интерфейс BYD только после успешной проверки нового APK.
