# Spotify для Android-магнитол

Экспериментальный плеер Spotify Automotive для Android-магнитол. Интерфейс на основе BYD и музыкальный сервис объединены в одном APK с одним значком и стандартным входом Spotify.

[Скачать тестовый APK](https://github.com/romanchukg-cloud/spotify-android-head-units/releases/tag/v5.5.0-headunit-test.4) · [🌐 Spotify для Android-магнитол](https://romanchukg-cloud.github.io/spotify-android-head-units/ru/)

## Что уже проверено

Headunit-test.4: аудит APK — 26 PASS / 0 FAIL. На эмуляторах Android 9 и 15 проверяются логика магнитолы, экраны без авторизации и настройки в пяти размерах, шифрованное хранилище, откат ошибок, перезапуск и переключение двух синтетических аккаунтов. Эти тесты не подтверждают авторизацию двух настоящих аккаунтов на сервере Spotify.

**Экспериментальная headunit-test.4.** Ещё не проверены просмотр и звук после входа, настоящее переключение A → B → A, офлайн-загрузки, кнопки руля, фактическое восстановление звука после сна/перезагрузки и регрессия на BYD/AAOS.

Требуется Android 9+ (API 28); Android 8 — следующий этап. Реализованы профили BYD, AAOS и GENERIC; в этой сборке проверен только GENERIC. Реальные магнитолы других производителей и AAOS ещё не проверены.

## Как установить

1. Скачайте APK из GitHub Releases и перенесите в мультимедийную систему.
2. Нашу предыдущую тестовую сборку с той же подписью обновляйте без удаления: авторизация может сохраниться. Сборки с другой подписью так не обновятся.
3. Откройте Spotify и при необходимости войдите по QR-коду.
4. Чтобы добавить другого водителя: Настройки магнитолы → Аккаунты → Добавить аккаунт · QR. Переключение останавливает музыку и перезапускает плеер.
5. Проверьте музыку и управление. Удаляйте старый отдельный интерфейс BYD только после успешной проверки нового APK.
