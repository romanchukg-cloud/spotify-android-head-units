## Что уже проверено

Headunit-test.18 показывает Spotify в аудиопанели Waze: трек, управление, сердце, перемешивание там, где Spotify его разрешает, а также Главную, Недавние, Обзор и Библиотеку. С test.17 загрузка и переходы плавные: вместо «Загрузка…» — заготовки в форме содержимого, содержимое плавно появляется, обложки проявляются, страницы въезжают сбоку, вкладки сменяются через затухание. С test.16 он показывает, где играет музыка, и переносит её между этой машиной и другими вашими устройствами (Spotify Connect); в мини-плеере есть время, перемешивание, повтор и устройства, вокруг экрана — тонкая рамка, а навигация сворачивает плеер на весь экран. С test.14 в нём также есть виджеты рабочего стола для лаунчеров, в которых можно добавлять виджеты (пять вариантов по размеру, день и ночь), открывает ссылки Spotify из других приложений, сообщает другим приложениям, что играет, и может запускать Spotify в фоне при запуске магнитолы (не на BYD). Сделано полной эталонной сборкой. Аудит релиза: 56 PASS / 0 FAIL; проходят 152 проверки обновлений, 39 входа, 14 доступа к блоку, 13 сообщений Connect, 66 App Remote и 19 запуска воспроизведения; сертификат подписи тот же, что в test.17. На эмуляторах Android 9 и 13 test.18 устанавливается обновлением поверх test.17 и без сбоев проверяет обновления; вход и «Аккаунты» проходят на Android 13. Виджеты проверены в стандартных лаунчерах эмуляторов Android 11 и 12; ссылки открывали там плейлисты, альбомы и исполнителей. Сборка с тем же кодом работает в BYD Tang (DiLink 5, Android 12); там Spotify открывался в аудиопанели Waze for BYD 5.22 с сердцем рядом с треком и перемешиванием в Liked Songs, а сердце работает в плеере; анимации там проверены с test.17, а перенос музыки на ноутбук и обратно — с test.16.

**Экспериментальная headunit-test.18.** Spotify в Waze проверен только с Waze for BYD 5.22 в одной машине; Waze один раз просит своё согласие и не показывает для него кнопку повтора. Перенос музыки проверен только с ноутбуком. Виджеты пока показывали только выдуманные треки, а штатный лаунчер BYD их не показывает. Воспроизведение песни по ссылке и настоящее приложение, читающее «что играет», не проверены. Правый руль не видели на машине с правым рулём; DiLink 5.1 / Android 13 и другие магнитолы не проверены; арабский проверен только на эмуляторе. Блок для панелей появляется только в приложениях с его поддержкой. Spotify держит загрузки выключенными для своего Automotive-клиента; эта сборка включает их поддержку, поэтому Spotify может изменить их работу.

Android 9+ (API 28). Ритм BYD проверен на DiLink 5 / Android 12; DiLink 5.1 / Android 13 и другие прошивки ещё не проверены. Профили AAOS и GENERIC реализованы; реальные магнитолы других производителей и AAOS ещё не проверены.

## Support and diagnostics

Open Head unit settings → Support. Send diagnostics lets you preview approved technical data before sending. Reports go to our shared server and a limited summary may appear in this project’s PUBLIC GitHub Issues. Automatically send diagnostics is selected on the first-use notice and starts only after Continue; you can turn it off in Support. Automatic reports cover measured integration failures only, at most one new report per day. Manual sending, pending status/cancellation and ZIP export remain available with automatic sending off. Reports exclude account data, song/playlist names, location and screenshots. Technical metadata is not a guarantee of anonymity.

## Как установить

1. Нажмите кнопку скачивания выше, чтобы получить APK, и перенесите его в мультимедийную систему.
2. Нашу предыдущую тестовую сборку с той же подписью обновляйте без удаления: авторизация может сохраниться. Сборки с другой подписью так не обновятся.
3. Откройте Spotify и при необходимости войдите по QR-коду.
4. Для подсветки BYD включите «Музыкальный ритм» в настройках салонной подсветки самого автомобиля. Этот переключатель в настройках машины, а не Spotify.
5. Чтобы добавить другого водителя: Настройки магнитолы → Аккаунты → Добавить аккаунт · QR. Переключение останавливает музыку и перезапускает плеер.
6. Проверьте музыку и управление. Удаляйте старый отдельный интерфейс BYD только после успешной проверки нового APK.
