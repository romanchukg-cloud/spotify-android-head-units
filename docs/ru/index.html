Экспериментальный плеер Spotify Automotive для Android-магнитол. Интерфейс на основе BYD и музыкальный сервис объединены в одном APK с одним значком и стандартным входом Spotify.

Один APK

Интерфейс и музыкальный сервис работают внутри одного установленного пакета.

Вход по QR-коду

Нажмите LOG IN, отсканируйте код телефоном и подтвердите вход в Spotify.

Автомобильный интерфейс

На основе плеера BYD, без обязательных разрешений на системы автомобиля BYD.

Что уже проверено

На эмуляторе Android 35 проверены установка, запуск интерфейса, подключение к внутреннему сервису и открытие экрана входа.

Этот единый APK ещё не проверен в автомобиле. Звук, каталог после входа, кнопки руля, закрытие во время воспроизведения и офлайн-загрузка требуют проверки.

Требуется Android 9 или новее. Совместимость с магнитолами других производителей ещё не проверена; это не универсальная сборка.

Как установить

  1. Скачайте APK из GitHub Releases и перенесите в мультимедийную систему.
  2. Нашу предыдущую тестовую сборку с той же подписью обновляйте без удаления: авторизация может сохраниться. Сборки с другой подписью так не обновятся.
  3. Откройте Spotify и при необходимости войдите по QR-коду.
  4. Проверьте музыку и управление. Удаляйте старый отдельный интерфейс BYD только после успешной проверки нового APK.
