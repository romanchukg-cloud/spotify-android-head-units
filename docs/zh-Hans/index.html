安装方法

  1. 从 GitHub Releases 下载 APK，并传输到车载多媒体系统。
  2. 如果已安装我们之前使用相同签名的测试版本，请直接更新，无需卸载，登录状态可能保留。签名不同的版本无法通过此方式更新。
  3. 打开 Spotify，按需扫码登录。
  4. 检查音乐播放和控制功能。确认新 APK 工作正常后，再卸载原来独立的比亚迪界面应用。
