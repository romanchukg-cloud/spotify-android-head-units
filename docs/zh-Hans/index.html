新版样式

更接近当前 Spotify 的全新设计：圆角卡片、Figtree 字体、随车辆切换的日间和夜间主题，以及封面取色。经典样式仍可在主机设置 → 外观中选择。

一个 APK

界面和音乐服务在同一个已安装的应用包内运行。

扫码登录

点击 LOG IN，用手机扫描二维码，然后确认登录 Spotify。

车载界面

基于比亚迪播放器界面，无需强制授予比亚迪车辆系统访问权限。

设置中的账号

打开主机设置 → 账号，可通过二维码添加账号、重命名已保存的账号或切换账号。

保持登录

固定设备 ID、安全移除旧账号以及每次启动一次的自动恢复，让 Spotify 保持登录。主机设置中显示最近一次登录事件。

应用内更新

Spotify 每天检查新的测试版本，并在你确认 Android 的“更新”窗口后安装。开关和按钮位于主机设置 → 更新。早于 test.9 的版本需手动更新一次。

播放启动

车机设置提供两个独立选项：在启动或长时间休眠后恢复播放，以及在新启动 Spotify 时播放。应用会等待播放器准备就绪；暂停会取消自动重试。

比亚迪氛围灯音乐律动

Spotify 会随播放启动和停止车辆原生灯光律动。请在车辆氛围灯设置中开启“音乐律动”；颜色和效果由车辆控制。

安装方法

  1. 点击上方下载按钮获取 APK，然后将其传输到车载多媒体系统。
  2. 如果已安装我们之前使用相同签名的测试版本，请直接更新，无需卸载，登录状态可能保留。签名不同的版本无法通过此方式更新。
  3. 打开 Spotify，按需扫码登录。
  4. 要使用比亚迪氛围灯，请在车辆自身的氛围灯设置中开启“音乐律动”。此开关位于车辆设置中，而不是 Spotify 中。
  5. 添加其他驾驶员：主机设置 → 账号 → 添加账号 · QR。切换时会停止音乐并重启播放器。
  6. 检查音乐播放和控制功能。确认新 APK 工作正常后，再卸载原来独立的比亚迪界面应用。
