🎵 Spotify for Android Head Units — test.22

Clearer sign-in errors, and a build for European cars to try.

• Sign-in: if you saw "Unknown error." after scanning the QR code, Spotify's server may be asking for Premium. The login screen now says so when it does. That decision is Spotify's, not the app's.

🇪🇺 Cars with Spotify built in: we need testers
The regular build can't be installed on these cars, because Android won't replace the built-in Spotify. This release adds a separate APK that installs next to it and shows up as "Spotify HU". You sign in to it separately, and the built-in app isn't touched.

Please try it and tell us whether it installs, whether sign-in and sound work, and whether the steering wheel buttons and the car's media card respond:
https://github.com/romanchukg-cloud/spotify-android-head-units/releases/download/v5.5.0-headunit-test.22/Spotify-5.5.0-HeadUnit-test.22-alongside.apk

Tell us here:
https://github.com/romanchukg-cloud/spotify-android-head-units/issues

So far it has only been tested on an emulator. It has no Waze panel and no in-app updates for now, so new versions have to be installed by hand. If it works in real cars, we'll add automatic updates.

⚠️ This app is free. If someone sold it to you, you were misled — ask for your money back. Download it only from the official page below. It is unofficial, not made by Spotify or BYD.

How to update the regular build: on test.9–test.21, Spotify offers test.22 inside the app, or open Head unit settings → Updates → Check. On older builds, install it once by hand as an update over your current build (don't uninstall).
